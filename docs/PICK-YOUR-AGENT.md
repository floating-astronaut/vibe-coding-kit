# Pick Your Agent

## Claude Code

Best for: long coding sessions, repo refactors, strong project memory, and non-engineer install walkthroughs.

Use when you want the smoothest "paste a prompt and let it work" experience.

## Codex

Best for: pragmatic repo work, server-side maintenance, test-driven fixes, and direct engineering tasks.

Use when you want precise code changes and verification.

## Cursor

Best for: editing inside an IDE with a visible file tree and quick code suggestions.

Use when you like steering changes manually while the AI assists.

## OpenClaw

Best for: local agent workflows that already depend on OpenClaw plugins.

Use when you already have OpenClaw installed. New buyers should generally start with Claude Code, Codex, Cursor, or Hermes.

## Hermes

Best for: persistent local agent gateway workflows, multi-channel operation, and users who want an open local control plane.

Use when you want a local agent runtime that can keep context and route tools.

## NemoClaw

Best for: OpenClaw-style experimentation where the user already knows that ecosystem.

Use only if you intentionally chose NemoClaw. It is not the beginner default.

## Aider

Best for: terminal-first code edits with git discipline.

Use when you are comfortable with commits, diffs, and command-line workflows.

## Recommendation

If you are non-technical: start with Claude Code or Cursor.

If you are technical and want precise repo work: use Codex.

If you are building a persistent local agent setup: use Hermes.
