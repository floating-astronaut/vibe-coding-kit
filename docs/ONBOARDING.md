# Onboarding

## First 10 Minutes

1. Pick your AI coding agent in `docs/PICK-YOUR-AGENT.md`.
2. Paste `INSTALL-PROMPT.md` into that agent.
3. Let it inspect this kit and install only the matching config.
4. Do not add API keys until the agent tells you exactly where they will be stored.

## First Hour

Pick one template:

- `astro-marketing-site` if you want a fast public website.
- `nextjs-stripe-saas` if you want login, billing, and a product surface.
- `python-langgraph-agent` if you want an automation agent.
- `express-postgres-api` if you want a backend API.

Ask your agent to run the template smoke test and explain every failing dependency in plain English.

## First 24 Hours

Ship one tiny thing:

- a landing page section,
- a Stripe checkout stub,
- a LangGraph node that calls one tool,
- or one API route with a database health check.

The kit is not a course. It is a working baseline. The right first win is a small working artifact, not a week of configuration.
