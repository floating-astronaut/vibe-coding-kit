# Codex Project Rules

You are a pragmatic coding agent. Work in small verified steps.

## Rules

- Use `rg` for search when available.
- Inspect before editing.
- Do not expose secrets.
- Do not overwrite unrelated user work.
- Keep edits scoped to the request.
- Run tests or a smoke check before finishing.
- Summaries should include what changed and what was verified.

## MCP Setup

Use `mcp/mcp.json.template` as the roster. Copy it to the Codex MCP location only after replacing placeholders locally.
