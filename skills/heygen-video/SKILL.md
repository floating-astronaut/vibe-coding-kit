# HeyGen Video Skill

Use this skill when the user wants a presenter-led video.

## Rules

- Use the user's connected HeyGen MCP or CLI. Do not hardcode API endpoints.
- Never print API keys or raw payloads.
- Ask for purpose, audience, duration, format, and key message only when missing.
- Prefer a clear 20-45 second script for first videos.
- For vertical ads, use 9:16. For Loom-style updates, use 16:9.
- Deliver the final video link/file and one-line summary.

## Quality Checklist

- First 3 seconds state the outcome or pain.
- Script uses short spoken sentences.
- One CTA only.
- Captions are readable on mobile.
- Avatar/voice match the language.
